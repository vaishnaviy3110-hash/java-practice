# Java OOP Programs

## About
This folder contains Java programs demonstrating the fundamental concepts of Object-Oriented Programming (OOP). Each program focuses on a specific concept to build a clear understanding of Java classes, objects, inheritance, and polymorphism.

## Concepts Covered

### 1. Classes and Objects
- `ClassAndObject.java` — Demonstrates class creation, object creation, and accessing instance variables and methods.

### 2. Constructors
- `ConstructorDemo.java` — Demonstrates parameterized constructors and object initialization.
- `ConstructorTypes.java` — Demonstrates default and parameterized constructors.

### 3. Encapsulation
- `EncapsulationDemo.java` — Demonstrates data hiding using private variables and public methods.

### 4. Abstraction
- `AbstractClassDemo.java` — Demonstrates abstract classes, abstract methods, and concrete methods.

### 5. Polymorphism
- `MethodOverloading.java` — Demonstrates compile-time polymorphism using method overloading.
- `MethodOverriding.java` — Demonstrates method overriding.
- `RuntimePolymorphism.java` — Demonstrates runtime polymorphism using parent class references and child class objects.

### 6. Inheritance
- `MultilevelInheritance.java` — Demonstrates multilevel inheritance.
- `HierarchicalInheritance.java` — Demonstrates hierarchical inheritance.

### 7. Interfaces
- `InterfaceDemo.java` — Demonstrates interface implementation.
- `MultipleInterfaces.java` — Demonstrates implementing multiple interfaces in Java.

### 8. Java Keywords
- `ThisKeyword.java` — Demonstrates the use of the `this` keyword.
- `SuperKeyword.java` — Demonstrates accessing parent class members using `super`.
- `StaticKeyword.java` — Demonstrates static variables and methods.
- `FinalKeyword.java` — Demonstrates the use of the `final` keyword with variables, methods, and classes.

## Technologies Used
- **Language:** Java
- **IDE:** Visual Studio Code
- **Version Control:** Git and GitHub

## Learning Objectives
- Understand the core principles of OOP.
- Learn how classes and objects work in Java.
- Practice inheritance, encapsulation, abstraction, and polymorphism.
- Understand constructors, interfaces, and commonly used Java keywords.
- Develop a strong foundation for advanced Java programming.

This collection is part of my Java programming practice, focused on strengthening object-oriented programming concepts through simple, practical examples.
